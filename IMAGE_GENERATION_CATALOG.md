## Target File Directory & Image Conventions

When you generate these images, save them into the project repository under:
```
public/
  ├── images/
  │    ├── brand/           # Logos, icons, bot avatars
  │    ├── collections/     # Category cards (1:1 & 16:9)
  │    ├── banners/         # Hero & AI showcase banners
  │    └── products/        # Product galleries: [slug]-[index].webp
```

Recommended Format: **WebP** or **PNG** (minimum 1200×1200 for square, 2400×1350 for 16:9).
